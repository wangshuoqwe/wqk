# 任务3 开源语音识别实验报告
## 一、三种开源ASR方案调研
1. Whisper
   - 支持多语言，中文识别精度高
   - 适合离线音频转写
   - 不支持实时流式识别

2. Vosk
   - 模型轻量，速度快
   - 支持实时麦克风识别
   - 部署简单，适合嵌入式/PC端实时场景

3. FunASR
   - 中文、方言识别效果优秀
   - 支持流式与离线
   - 部署相对复杂

## 二、选型方案
- 音频文件识别：Whisper base
- 实时语音识别：Vosk 轻量中文模型

## 三、实现步骤
1. 安装依赖库：pip install -r requirements.txt
2. 下载并解压Vosk模型
3. 运行whisper_file.py完成配音音频识别
4. 运行vosk_realtime.py实现实时麦克风识别

## 四、实验结果
1. Whisper 对克隆音频识别准确，专业术语无明显错误。
2. Vosk 实时识别延迟低、占用资源小，满足课堂实验要求。
3. 两段代码均可在 Windows 上稳定运行，复现性好。
