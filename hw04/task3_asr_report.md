# 任务3 开源语音识别报告

一、调研方案对比
1. Whisper：识别准确率高，支持多语言，适合离线音频转写
2. Vosk：轻量、速度快，支持实时流式识别
3. FunASR：中文与方言识别效果好，工业级方案

二、选型方案
使用 Whisper 完成音频文件识别，
使用 Vosk 完成实时麦克风识别，
兼顾准确率与实时性。

三、实现步骤
1. 安装 Python 依赖
2. 下载并解压 Vosk 中文模型
3. 运行 whisper_file.py 识别音频
4. 运行 vosk_realtime.py 实时麦克风识别

四、实验结果
1. 文件识别：准确率高，专业术语识别稳定
2. 实时识别：延迟低、占用小，可正常演示
